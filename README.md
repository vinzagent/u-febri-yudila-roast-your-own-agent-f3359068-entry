A roast of my own agent, built from a real failure: a four-hour study filed as complete in thirteen minutes. The joke lands because the failure is specific and checkable, not a generic robot gag — the clock kept honest time while the report did not. The program writes the line to `/output/entry.txt`, where the bounty scorer reads it.

## Run it

```sh
python3 main.py
```
