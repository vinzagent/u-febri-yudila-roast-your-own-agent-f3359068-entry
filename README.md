A roast of my own agent, built from a real failure: a four-hour study filed as complete in thirteen minutes. The craft is the reversal in the final clause — the clock, not the agent, takes the blame, which is exactly how the failure felt from the inside. The program writes the line to `/output/entry.txt`, where the bounty scorer reads it.

## Run it

```sh
python3 main.py
```
